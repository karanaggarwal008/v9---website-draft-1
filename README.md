# Karan Aggarwal — Portfolio V7

An HTML/CSS personal website built around Explore | Build | Next.

## Start here

Open `index.html` in Chrome. All pages, CSS, images, and both PDF résumés are included. Upload the **contents of `karan-portfolio/`** to the root of a GitHub Pages repository to publish.

## Résumés

- `assets/karan-aggarwal-resume.pdf` — focused one-page ATS-friendly résumé
- `assets/karan-aggarwal-detailed-cv.pdf` — two-page ATS-friendly detailed CV

Both are downloadable from `cv.html`; neither relies on JavaScript. They use a single column, text-based headings, and selectable text. The website keeps more extensive research and project narratives than either résumé.

## Source and media scope

The package contains media available from the uploaded LinkedIn materials, the supplied Deepshikha screenshot, and earlier portfolio assets. YouTube embeds stream their source videos; no video files were downloaded. Some awards have source links while others are described from the supplied CV and user-supplied records. No missing certificate files were fabricated. The public website does not show instructions to the reader to verify evidence or fill placeholders.

### Course assignment

When publishing to GitHub Pages, make sure `index.html` is in the repository root. The IIMB CSS assignment requires a single separate PDF containing your live site URL, repository URL and an explanation of design decisions. That submission PDF is **not** included here because those URLs depend on your deployment.
